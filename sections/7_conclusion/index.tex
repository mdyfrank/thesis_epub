\chapter{Conclusion}\label{chpt:conclusion}

This dissertation investigates how to enhance personalized RecSys by coupling graph learning with the semantic knowledge and the reasoning ability of language models. Traditional RecSys rely mainly on user-item interaction data, which is sparse and carries little information about what the items themselves mean. The five frameworks presented here address this gap from different directions, first by enriching the relational structure that a recommendation model can see, then by injecting semantic guidance into that structure, and finally by moving language model reasoning to the decision stage.

\section{Summary of Contributions}

\begin{itemize}[left=0pt]

\item We develop a unified multitask pretraining framework UPRTH for recommendation based on task hypergraphs.
It models diverse auxiliary tasks as hyperedge prediction problems and employs a transitional attention mechanism to selectively transfer useful knowledge, enabling effective integration of heterogeneous relational signals and alleviating data sparsity.

\item We introduce an instruction-based hypergraph pretraining framework IHP to incorporate semantic task guidance into hypergraphs for recommendation.
By encoding textual instructions with a pretrained language model and injecting them into hypergraph convolution, IHP aligns structural relations with semantic task descriptions and improves cross-domain knowledge transfer in recommendation.

\item We propose a graph-language alignment framework GLTA to integrate semantic knowledge from LLMs into recommendation models.
It aligns graph-based user and item representations with token embeddings from pretrained language models, allowing recommendation models to inherit semantic knowledge while preserving the efficiency and determinism of ID-based item prediction.

\item We design an LLM-guided relational modeling method ERLSC to capture substitute and complementary item relations.
It leverages LLMs to infer functional relations between items and integrates these signals into hypergraph convolution through adaptive hyperedge weighting, enabling recommendation models to emphasize semantically meaningful item groups.

\item We propose an LLM-agent framework for dynamic recommendation AgentDR. It treats the LLM as a high-level decision maker that coordinates multiple recommendation tools such as graph-based CF, and performs reasoning over item relations to refine candidate items, improving recommendation quality while maintaining scalability.

\end{itemize}

\section{Cross-Chapter Synthesis and Findings}

Although the five frameworks were developed and evaluated in distinct research settings, reading their findings together reveals several broader conclusions that no single chapter establishes on its own.

The first observation concerns the modeling interface. Hypergraphs recur in Chapter~\ref{chpt:uprth}, Chapter~\ref{chpt:ihp}, and Chapter~\ref{chpt:erlsc}, and in each case they carry a different kind of relation. A hyperedge is a pretext task in the first, a task shared between two domains in the second, and an item group induced by co-occurrence in the third. The three frameworks retain a common node-hyperedge aggregation backbone while adapting it to different structural, semantic, and task-specific signals, which suggests that the hypergraph is acting less as a particular model and more as a general interface through which heterogeneous and higher-order relations can be attached to a recommendation model without redesigning it. The same interface also turns out to be a convenient place to deposit knowledge that comes from outside the interaction data, since a hyperedge weight is a natural carrier for a semantic judgment.

The second observation concerns the role that the language model plays. Chapter~\ref{chpt:uprth} transfers knowledge purely structurally, by learning which auxiliary tasks are relevant to recommendation. Chapter~\ref{chpt:ihp} shows that describing those tasks in text and encoding the descriptions with a PLM supplies information that structure alone does not carry, which matters most when two domains share users but no items. Chapter~\ref{chpt:glta} moves the same idea to a finer granularity by aligning representations with individual language tokens rather than with one vector per task. Chapter~\ref{chpt:erlsc} changes the kind of knowledge rather than its granularity, asking an LLM about item function instead of about task semantics. Chapter~\ref{chpt:agentdr} changes the timing, asking the model to decide rather than to encode. The progression from structural transfer to semantic guidance and then to explicit reasoning is therefore not a single axis of increasing model size, but a sequence of choices about what is asked of the language model and when.

The third observation concerns cost. Coupling becomes tighter from Chapter~\ref{chpt:ihp} to Chapter~\ref{chpt:glta}, and the computational burden rises with it, because token alignment requires gradients to pass through the language model while prompt encoding requires only a forward pass that can be cached. Chapter~\ref{chpt:erlsc} and Chapter~\ref{chpt:agentdr} deliberately reverse this direction. Offline relation inference pays for the language model once and reuses its output as a fixed structural signal, and inference-time reranking touches only a bounded candidate list. Both remain useful without backpropagating through a model whose size keeps growing, which is the practical reason the tightest coupling is not always the right target.

The fourth observation concerns grounding. Every framework in this dissertation returns item identifiers that exist in the catalog, and each achieves this differently. GLTA predicts through logits matching over the aligned token space instead of generating item names, and AgentDR delegates full-catalog ranking to conventional retrievers and confines the language model to reordering what those retrievers return. This is what allows the agent to reason without hallucinating items, and it suggests that grounding is better treated as an architectural constraint than as a post hoc filter.

Taken together, these observations indicate that no single coupling strategy dominates. Tight representation-level coupling is preferable when the recommendation model is trained from scratch and the semantic content of items is rich enough to justify the training cost. Offline relation inference is preferable when the useful knowledge is relational and stable, since it can be computed once and reused. Decision-level reasoning is preferable when several retrieval signals are available and the difficulty lies in choosing among them for a particular user. Because the five studies use different datasets, different baselines, and different evaluation protocols, their numbers are not directly comparable, and the conclusion drawn here is about where each strategy applies rather than about which one scores higher.

\section{Future Directions}

The five frameworks sit within a longer line of work for which I am also the primary author, and which shaped the questions this dissertation asks. Ranking-based group identification required item interactions and group participation to be modeled within a single social tripartite graph, which made clear that useful relational evidence often connects more than two entities at once and motivated the hypergraph formulation used throughout~\cite{cfag}. Transitional hypergraph convolution then let preferences learned over one type of entity serve as prior knowledge for another, and it reappears as the transitional attention layer of Chapter~\ref{chpt:uprth}~\cite{gtgs}. Prompt-based continual learning showed that a compact prompt can retain task-specific information while a user model is updated, a role that plain-text instructions play again in Chapter~\ref{chpt:ihp}~\cite{pcl}. Personalized tool learning showed that an agent can reflect on its own ranking outcomes to decide which recommendation model to trust for a given user, a mechanism that Chapter~\ref{chpt:agentdr} carries over to substitute and complement intent~\cite{prta}. Each thread began with a structural question and arrived at a semantic one, which is the same movement the chapters here follow, and the directions below continue it.

One direction concerns the robustness of signals derived from language models. A judgment about item function is stored as a hyperedge weight in Chapter~\ref{chpt:erlsc} and acted upon at inference time in Chapter~\ref{chpt:agentdr}, and in both cases a wrong judgment is treated exactly like a correct one. Separating the contribution of the relation type from the contribution of the model that supplied it, and characterizing how performance degrades as annotation quality falls, would show how much of the observed gain transfers across language models.

A second direction concerns cost. Token alignment, offline annotation, and inference-time reranking incur costs of different kinds, respectively in training compute, in one-time annotation, and in per-request latency, and this dissertation compares them qualitatively rather than on a common scale. A systematic accounting would make the choice among coupling strategies easier to justify for a given deployment.

A third direction concerns evaluation. The protocols used throughout are static and offline, replaying historical interactions and measuring ranking quality against held-out items. This suits the models studied here but only partially suits an agent whose tools and prompts could change between sessions. Offline replay cannot observe how a user would respond to an explanation, how tool selection would drift as a catalog evolves, or how an agent would behave when its available tools disagree.

The final direction is one this dissertation can only begin. Existing RecSys operate within a single platform or dataset, whereas a user-owned agent could aggregate information across multiple online services and reason about the most suitable choices for the user. Two obstacles have kept this out of reach. Technically, earlier models lacked the capability to integrate and reason over heterogeneous information sources at scale. From an ecosystem perspective, modern RecSys are largely developed by individual service providers whose objectives center on business metrics such as user engagement and conversion, which leaves platform-independent recommendation poorly aligned with existing incentives.

Recent advances in LLMs may begin to change the technical side of this situation. The ability to reason over diverse information sources makes it possible to build agents that assist users across platforms, and the design of Chapter~\ref{chpt:agentdr} is a step in that direction, since an agent that coordinates external retrieval tools does not need to own the data those tools index. At the same time, the cost of developing and deploying such agents continues to decrease, and the tools for building them are becoming more accessible, which suggests that users may eventually be able to build or customize their own recommendation agents.

Realizing this would require progress on the concerns raised above. Cross-platform aggregation raises questions of data access and privacy that a single-platform evaluation never encounters, since an agent acting on behalf of a user must read from services that were not designed to share. The dependence of LLM-derived signals on the querying model becomes more consequential when the agent, rather than the platform, is the party the user trusts. Static offline evaluation is least adequate exactly in this setting, so protocols that measure how such agents behave over time, and how much control they actually return to users, would need to be developed alongside the methods themselves.

If these problems can be addressed, user-owned recommendation agents may represent a meaningful step toward giving users greater control over how information is filtered and recommended, and toward mitigating practical concerns associated with platform-centric RecSys, such as data privacy risks and information cocoons. It is our hope that the ideas explored in this dissertation will inspire future research toward RecSys that not only understand user preferences, but also reason about information in a way that better serves users in an increasingly complex digital ecosystem.
